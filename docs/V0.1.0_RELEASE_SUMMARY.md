## Setup & Deployment

### Local Installation

```bash
# Create environment
python -m venv .venv
source .venv/bin/activate

# Install
pip install -e .

# Verify
logicllama --help

# Run UI
streamlit run src/ui/app.py
```

### GitHub Secrets (for CI & RAG)

1. Go to repository **Settings** → **Secrets and variables** → **Actions**
2. Add `OPENAI_API_KEY` (optional, for RAG features)

See [DEPLOYMENT_AND_SECRETS.md](DEPLOYMENT_AND_SECRETS.md) for full instructions.

### CI/CD Pipeline

Automated on every push/PR to `main`:
- Test Python 3.8, 3.9, 3.10, 3.11, 3.12
- Install editable package
- Run pytest suite
- Results visible under repository **Actions** tab
