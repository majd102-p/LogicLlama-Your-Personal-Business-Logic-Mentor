# Release v0.1.0

Release: v0.1.0 — Initial public packaging of LogicLlama

Highlights
- Archive: long-form professional docs moved into `docs/archive/` for cleaner root layout.
- Packaging: `pyproject.toml` added with `hatchling` build backend and CLI entrypoints.
- Scripts: verification and utility scripts moved into `scripts/`.
- RAG MVP: small retrieval-augmented generation (RAG) MVP scaffold added (`src/rag/mvp.py`) and demo script (`scripts/run_rag_mvp.py`).

Notes
- The repository is ready for a public release as a Python package; see `pyproject.toml` for metadata and `README.md` for QuickStart.
- CI workflow has been added to run tests on push and PRs.
